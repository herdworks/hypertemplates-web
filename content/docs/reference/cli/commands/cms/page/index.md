## `hyperctl cms page` command

<auto-toc selectors="h3,h4,h5,h6"></auto-toc>

### Overview 
------------

The `hyperctl cms page` command manages website pages.

### Usage
---------

```plaintext
$ hyperctl cms page -h
Manage pages and drafts.

Usage:
        hyperctl cms page [command] [options]

Available commands:
        ls       List website pages.
        inspect  Inspect website pages.

Options:
        -h, --help  Display help information.
```

### Commands
------------

The `hyperctl cms page` command has the following subcommands:

**`ls`**
: The `hyperctl cms page ls` lists website pages.

**`inspect`**
: The `hyperctl cms page inspect` inspects website pages.
