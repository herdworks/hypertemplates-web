## `hyperctl cms new` command

<auto-toc selectors="h3,h4,h5,h6"></auto-toc>

### Overview
------------

The `hyperctl cms new` command is used to start new HyperTemplates projects (websites) and add content (pages) to an existing project.

### Usage
---------

```plaintext
$ hyperctl cms new -h
Create a new website or page.

Usage:
        hyperctl cms new [command] [options]

Available commands:
        website  Create a new website.
        page     Create a new page.

Options:
        -h, --help  Display help information.
```
