### Review
----------

Thank you for completing the "Learn HyperTemplates" tutorial! 🏆

In these five lessons we introduced the core building blocks of the HyperTemplates pure-HTML templating system:

* [`ht-apply`]
* [`ht-if`]
* [`ht-include`]
* [`ht-each`]

These core directives are all you'll need 99% of the time.
However, there are also some more advanced template directives that weren't covered in this guide, including [`ht-block`], and [`ht-pipe`].
